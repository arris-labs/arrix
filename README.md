# ArriX

A free, pure-Rust parametric CAD with a small, solid core and everything else
as plugins. It is built on the [Arris](https://crates.io/crates/arris) B-Rep
kernel, runs natively and in the browser, and takes plugins in Rust and
Python.

Status: seeded, no code yet. [`SEED.md`](SEED.md) is the charter; the design
lives in [`docs/`](docs/README.md).
