the command registry and the setting specs; a test holds it fresh. Do not edit.
`arrix describe --json` gives the same, with the effective values, and
`arrix config schema` the files' JSON Schemas.

## Ribbon tabs (`ui.ribbon.hidden-tabs`)

- `core.sketch`: Sketch
- `core.part`: Part
- `gears`: Gears

## Keymap contexts (`when`)

- `part`: the document is shown and no sketch is being edited
- `sketch`: a sketch is being edited
- `form`: a property form is open and no text field has focus; its keys win over `sketch-tool`'s
- `sketch-tool`: a sketch is being edited with a drawing tool; its keys win over `sketch`'s
- `palette`: the command palette is open
- `text`: a text field has focus; only bindings that name it fire

## Theme roles (`themes/<name>.toml`)

|---|---|
| `panel` | The background of the ribbon, the panels and the status bar. |
| `window` | The background of floating windows, the palette's included. |
| `field` | The background of text fields and of the viewport. |
| `text` | Labels and other text that does nothing. |
| `text-widget` | The text of buttons and tabs at rest. |
| `text-hover` | The text of a button or tab under the pointer. |
| `text-active` | The text of a button or tab being pressed. |
| `border` | Separators and the outline of panels and windows. |
| `button` | The background of a button or tab at rest. |
| `button-hover` | The background of a button or tab under the pointer. |
| `button-active` | The background of a button or tab being pressed. |
| `accent` | The background of a selection. |
| `accent-text` | The outline of a selection. |
| `link` | Links. |
| `warn` | Warnings. |
| `error` | Errors. |
